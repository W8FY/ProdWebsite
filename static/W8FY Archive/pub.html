Public Awareness

 

Here we have a way to advertise the club, promote amateur radio, and provide a handy reference guide to the public as well as ourselves.  Created by Steve Kouts, WA8WKF, this single sheet, tri-fold is both informative and convienent.  Just push the GO button. Click the print button in Adobe Reader. Set Print Scaling to None then print so you have page 1 on one side and page 2 on the other of the same sheet.  With page 2 facing up, fold in the right side between the collums, then the left and you have it.  If you don't want to do that, then attend the next club meeting, we have some already made up for you.
