Creating and Changing user accounts in xp

To open the User Accounts tool, open Control Panel from the Start menu, and then double click User Accounts.

To Create a New User Account

1.     Click Create a new account in the Pick a task list box.

2.     Type the name that you want to use for the account, and then click Next.

3.     Select the desired account type, and then click Create Account.

4.     Give this account a secure password.

5.     Go back to the start menu and log out. 

6.     Log back on to the new account so you can make changes to your old account

 

To Make Changes to an Account

1.     Click Change an account in the Pick a task list box.

2.     Click the account that you want to change.

3.     Select the item that you would like to change:

o    Click Change the name to change the name that appears on the Welcome screen for the account.

o    Click Change the picture to change the picture that is used to represent the user account. You can use any image file on the computer for the user's picture.

o    Click Change the account type to change the account type to increase or decrease the user's rights on the computer. You will want to use limited for your main account. This is the one you want to 

       use all the time.

o    Click Create/change the password to create or change the password for the user and create or change the password hint.
